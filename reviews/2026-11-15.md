## Selection and missing-data rules

- Exact `(scope, model)` names are required. An API reference or proxy label
  does not prove which backend a third-party service used or its actual bill.
- All values are USD per million **text** tokens. Provider-global Standard
  rates are used unless a row explicitly names another deployment or tariff.
  Qwen rows use the International deployment, with decimal K/M units as
  defined in its pricing page. Regional rates are not silently combined.
- `valid_from` and `valid_until` are inclusive. New provider snapshots begin
  November 15 and do not backdate current rates into earlier unknown usage.
- `request_input_min` and `request_input_max` are inclusive **single-request**
  input-token bounds, including cached input. A daily/session aggregate cannot
  identify a request tier. Conditional rows return no price without this count.
- `rate_tier` distinguishes Standard, named service/context bands and peak/off-peak
  prices. The caller must supply a non-Standard tier explicitly. Unknown conditions
  return no price instead of selecting a low price. Tier ranges must not overlap
  in date, request length and service band.
- DeepSeek peak hours are 01:00–04:00 and 06:00–10:00 UTC on weekdays excluding
  Chinese public holidays; the remaining periods are off-peak. Both rates are
  retained. No holiday or request-time decision is inferred from a daily total.
- Haiku 5.5 switches above 100,000 input tokens. Grok's long-context tier starts
  at 200,000. Qwen Flash uses its documented 32K/256K thresholds. All token legs
  in an affected request use that request's tariff.
- MiniMax publishes a `512k` context boundary without an unambiguous numeric
  unit conversion in the checked page. Its Standard/Priority short/long rates
  are retained as explicit named bands; the catalog does not invent a numeric
  threshold or select the short band by default.
- The Qwen 3.7 Plus alias's current temporary 20% discount has no published end
  date in the reviewed table. Its discounted snapshot covers November 15 only;
  the separately listed dated model retains its own published rates.
- A missing cache-read/write field means **unknown**, not free. Qwen cache
  prices differ by cache mode and deployment. Cohere's checked R-family sources
  do not establish cache rates. These fields stay absent. Client scopes continue
  to require their established cache-read reference.
- Claude and Kimi cache-write rates depend on TTL. OpenAI separately lists 30m
  and 12h writes. No single unspecified write fee is invented. Existing Claude
  Code receipts with only aggregate writes price known input, cache reads and
  output, while keeping writes unpriced; all tokens remain counted.

## Current alias and coverage boundaries

The [Google pricing page](https://ai.google.dev/gemini-api/docs/pricing#gemini-2.5-pro)
now says retired `gemini-2.5-pro` calls are served and billed as Gemini 3.8 Flash.
That reference is recorded from this review, not backdated to an unknown change
date. Carbon/Argon December and Flash January price transitions remain explicit.

[Cohere's current model list](https://docs.cohere.com/docs/models) identifies
Command A+, while the checked public sources did not expose a numeric first-party
A+ token rate. No neighboring R/R+ rate is assigned to it; Model Vault GPU rates
are not treated as token prices. Unverified rates, private discounts and unsupported
currencies remain outside this USD text catalog. Audio, image, video, OCR, embedding,
reranking, storage and tool fees use other units/contracts and are not represented
as invented text-token rates.

## Consumer compatibility and validation

The paired strict checker/consumer allowlist the provider scopes, optional cache
references and qualified periods under `api-price/v1`. Older strict consumers
reject unsupported rows and retain their last known good catalog. Exact lookup
is indexed by scope/model; expansion does not add model requests or telemetry.

Validation covers schema and manifest agreement; no overlapping qualified rows;
inclusive request boundaries and dates; unknown conditions; distinct service
rates; preserved historical monetary values; exact effort overrides; unknown
cache prices; and replay through the actual Infra Sentinel receipt consumer.
The native app is validated separately from this source catalog. No public release
is implied by the local update.
